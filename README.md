# 橙果·课后成果记录 —— 微信小程序版

由 H5 版完整移植的原生微信小程序工程，功能与线上的 H5 版对齐，并新增**线上数据同步**能力。

## 一、功能清单（与 H5 版对齐）

| 模块 | 说明 |
|---|---|
| 首页 | 老师按班级查看学生卡片 + 最近一次成果摘要；家长端查看孩子列表；下拉刷新触发云端同步 |
| 录入 | 学生多选、0-100 分滑杆、待提高/良好/优秀标签、课程 picker、微信风格留言条（模板按钮+录音按钮内嵌） |
| 评价模板 | 5 个默认维度 × 多选项；跨维度多选批量插入（「维度：内容」逐行写入留言）；每维度支持 ＋新增 / ✎编辑 / ✕删除 选项，全部持久化 |
| 媒体 | 拍照 / 相册（wx.chooseMedia，最多 9 张，压缩），预览大图、删除 |
| 语音 | RecorderManager 录音（最长 60s），线上模式自动上传并生成可播放链接 |
| 记录 | 按班级筛选的记录列表（缩略图/分数/评价/已发送状态），支持编辑（原地更新） |
| 学生详情 | 最近一次重点展示 + 历史课程列表；照片九宫格预览 |
| 学生资料 | 家长填写（昵称/生日/学校/电话/微信/水平/目标/备注），手机号校验 ^1\d{10}$，提交保存到系统 |
| 管理 | 班级 → 课程 → 学生 三个 tab，增删管理 |

## 二、导入运行（5 步）

1. 下载安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开开发者工具 → 导入项目 → 选择本目录 `橙果-小程序/`
3. AppID：测试可用默认 `touristappid`；正式使用请填你在 [微信公众平台](https://mp.weixin.qq.com) 注册的小程序 AppID
4. 点「编译」即可在模拟器/真机预览运行（默认纯本地模式，数据存本机 storage）
5. 真机预览：工具栏「预览」扫码即可

## 三、开启「线上操作」（微信云开发，已接入）

代码已全面接入微信云开发（免运维、免域名备案）：

1. 开发者工具打开项目 → 工具栏点「云开发」→ 开通，创建环境（如 `chengguo-0gxxx`）
2. 把环境 ID 填到 `utils/api.js` 顶部的 `CLOUD_ENV`
3. 在数据库控制台创建两个集合：`records`（课后记录）、`profiles`（学生资料），权限选「仅创建者可读写」
4. 右键 `cloudfunctions/sync` → 「上传并部署：云端安装依赖」
5. 重新编译。之后：保存记录自动写入云数据库、照片/语音自动传云存储（`cloud://` fileID 可直接展示）、启动自动按 id 合并拉取，家长提交的资料也实时上云

云函数说明（`cloudfunctions/sync`）：
- `push`：记录按 id upsert；学生资料按 sid upsert，自动打上 openid 归属
- `pull`：返回该用户全部记录与资料，小程序端按 id/updatedAt 合并
- 多老师隔离：每条数据带 `owner` openid，天然按账号隔离；机构多老师共享同一班级数据需 V2 扩展（可把 owner 换成 orgId）

## 四、语音转文字（已接入）

- 已接入官方「**微信同声传译**」插件（`app.json` 已配置 `WechatSI`，封装在 `utils/stt.js`）：
  - 录入页留言条麦克风：点击开始听写，识别文字实时写入留言框，说完再点结束，可手动修改；识别失败自动提示。
  - 模板页每个维度的麦克风：说话内容自动成为该维度的新选项。
- **启用步骤**：在微信公众平台（小程序后台）→「设置 → 第三方设置 → 插件管理」搜索并添加「微信同声传译」（appid `wx069ba97219f66d99`），开发者工具重新编译即生效。
- 插件不可用时自动降级：留言走录音附件（wx 录音+线上上传），模板页提示手动新增。

## 七、自动部署上线（CI）

微信小程序**无法跳过审核自动发布**，但可以用官方 `miniprogram-ci` 实现「一条命令自动上传新版本」，把人工操作压缩到后台点两次：

```
本地/CI 机器：node deploy.js <版本号>   → 自动上传开发版本
微信公众平台：版本管理 → 设为体验版（给老师用）→ 提交审核 → 审核通过后发布
```

**启用步骤**：
1. `npm i`（安装 miniprogram-ci）
2. 公众平台 →「开发管理 → 开发设置 → 小程序代码上传」：下载**代码上传密钥**，保存为本目录 `private.key`（同时按需配置 IP 白名单）
3. 把 `deploy.js` 里的 `APPID` 改成你的 AppID
4. `node deploy.js 1.0.1` —— 上传成功后版本出现在后台「版本管理 → 开发版本」
5. 进阶：**已内置 GitHub Actions 流水线**（`.github/workflows/deploy.yml`）——把工程推到 GitHub 仓库，配置两个 Secrets（`MINI_APPID`、`MINI_UPLOAD_KEY`），push 到 main 即自动上传新版本

**云函数部署**也可自动化：`miniprogram-ci` 的 `cloud.uploadFunction` 或开发者工具命令行 `cli cloud functions deploy --e <env> --n sync --path cloudfunctions/sync`。

**审核提示**：教育类目小程序需提供主体资质（机构/学校或个人开发者教育工具类目），首次提交前在「设置 → 基本设置 → 服务类目」配好，可显著降低被拒概率。
