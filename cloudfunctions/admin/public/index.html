数据体检
检查学生、老师（成员）、机构之间的引用是否对得上：学号有没有重复、学生是不是挂在已删除的班级上、 记录有没有指向不存在的孩子、同一个微信是不是绑成了两个成员。
完整备份
导出全部学生、老师（成员）、机构、班级、学期、报名与课堂记录为一个 JSON 文件。 和上面的 CSV 不同，这份是完整快照（所有字段都在），适合归档、留底或换系统时迁移。
建议每周下载一次，存到自己的网盘或电脑里。
云端每日备份
云开发每天凌晨 3 点自动把全部数据打包存到云存储，保留 30 天。这是「云数据库被改坏了」 时的最后一道保险：手机快照救不了这种情况，因为它拉回来的也是坏数据。
恢复只写回、不删除：备份之后新录的数据不会被抹掉。恢复完让老师打开一次小程序即可同步到手机。
