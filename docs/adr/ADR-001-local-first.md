# ADR-001：本地优先存储 + 云函数同步（而非直连云数据库）

## 状态
Accepted（2026-11-09 追认；实际决策更早，本文补记）

## 背景
老师录课的场景是「教室里网络很差、甚至没有网」。若数据直接落在云数据库（在线优先），
断网即不可用；若只在本地，换手机/多人协作/家长端查看都没有地基。

## 决策
**本地优先**：所有写入先落本机分片存储（`utils/db/storage.js`，wx storage 10MB 上限分片管理），
读路径只碰本地；**云同步**作为第二层（`utils/sync.js` + `cloudfunctions/syncv2`）：
写后 1.5 秒自动推、断网退避重试、增量拉取（srvAt 游标）。
云端不是「数据的家」，是「多设备与家长端的分发枢纽」。

## 后果
- **得**：断网完全可用；云函数挂了只影响同步不影响上课；冷启动读数据零网络。
- **失**：同一份数据两端各存一份，必须回答「冲突怎么办」（见 ADR-002）；
  本地存储 10MB 上限要求控制复制范围（见 ADR-005 的按班级订阅）。
- 备选路径（自建 Express 服务）冻结在 `server/`，见 `docs/freeze-list.md`。
