# ADR-002：LWW 冲突策略 + 败者副本兜底

## 状态
Accepted（2026-11-09 追认；败者副本为当日补强）

## 背景
本地优先意味着同一份文档可能在两台设备上被各改一次。必须回答「谁赢」。

## 决策
**整条 LWW**（最后写入胜）：比 `updatedAt`，时间相同「活着的优先」（防同毫秒删除静默吞数据）。
**不做字段级合并**：评语和分数是整段写的，字段级合并会拼出一条谁都没写过的记录。
**败者不静默消失**（2026-11-09 补强）：判负且内容真不同时，败者整条存进
`meta.sync.conflicts`（本机、上限 20 条），存储空间页可查看并以当前时间戳找回。

## 后果
- **得**：行为可预期、实现便宜；教学场景里冲突罕见且代价小（重写一条评语）。
- **失**：并发编辑时后写覆盖先写，**没有交互式合并**——这是明确放弃的；
  败者副本把「静默丢失」降级为「可找回的丢失」，但没有通知推送。
- 放弃 CRDT/OT：场景不值得（同班并发编辑同一学生的同一条记录概率极低）。
