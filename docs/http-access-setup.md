# 电脑端后台：配一条 HTTP 访问路由（约 3 分钟）

> **代码侧已经全好了，只差控制台点一次。**
> `cloudfunctions/admin/index.js` 已经能处理 HTTP 请求（`httpMethod` / `requestContext`）：
> GET 返回 `public/index.html` 登录页，POST 走后台接口，返回带 `statusCode + headers + body` 的标准格式。
> 配完立即生效，**不用重新部署云函数、不用改小程序、不用重新上传体验版**。

> 11-07 复测：`GET https://cloud1-d9gca4e7q307c4564.service.tcloudbase.com/admin`
> 返回 `{"code":"INVALID_PATH"}`。**网关是通的、域名是对的，只是没有 `/admin` 这条路由**——
> 这正是"HTTP 访问服务未配置"的证据，不是环境没开通、也不是函数没部署。

## 一、逐屏点击（认字段，不认按钮位置）

> 两代控制台界面差别很大，但**要做的都是同一件事：把 `/admin` 这条路径绑到 `admin` 云函数**。
> 找不到按钮时，找这几个词：`HTTP 访问服务`、`HTTP 网关`、`HTTP 触发路径`、`添加路由`、`路由管理`。

**第 0 步 · 打开控制台（二选一）**

- **A. 微信开发者工具（推荐，不用另记账号）**：顶部 **云开发** → 直接进入当前小程序的云开发控制台
- **B. 浏览器 / 腾讯云**：打开 https://tcb.cloud.tencent.com/dev →
  登录方式选 **微信公众号 / 小程序扫码**，用**小程序管理员**的微信扫码 →
  在授权页**选中这个小程序** → 进入「云开发 CloudBase」→ 选对应环境
  > 别用普通腾讯云账号登录，那样看不到小程序云开发的环境，是最常见的"进去找不到环境"。

**第 1 步 · 确认环境**：页面顶部的环境下拉选 `cloud1-d9gca4e7q307c4564`。
选错环境 = 把路由配到别的库里，白忙一场。

**第 2 步 · 打开 HTTP 访问服务，并确认全局开关**

左侧菜单 **环境管理 → HTTP 访问服务**（新版叫 **HTTP 网关**）。
页面顶部如果有「HTTP 访问服务」**开关，先打开**——**开关关着时路由不生效**，
这是最容易漏的一步，也是最像"配了没用"的原因。

**第 3 步 · 新建一条路由**

进 **路由管理** → 点 **添加路由 / 新建**，按第二节四项填写 → 确定。

> 有的界面更省事：直接进 **云函数 → `admin`** 的详情页 → 右上角「编辑」→
> **HTTP 触发路径** 填 `/admin` → 保存。这和「添加路由」是同一件事，看到哪种用哪种。

**第 4 步 · 抄下控制台给出的完整链接**

建完列表里会出现一条可点击的路径链接，**以它显示的域名为准**（见第三节的坑）。

**第 5 步 · 等 3~5 分钟**让网关生效，再按第四节验证。

## 二、新建路由要填的四项

| 配置项 | 填什么 | 说明 |
|---|---|---|
| 域名 | **默认域名** | ⚠️ 下拉里优先选 `cloud1-...4564.service.tcloudbase.com`，见第三节 |
| 触发路径 | **`/admin`** | 带开头斜杠，不带结尾斜杠；别写成 `admin` 或 `/admin/` |
| 关联资源类型 | **云函数** | 不要选静态托管 / 云托管 |
| 云函数 | **`admin`** | 不是 `admin/` 也不是 `syncv2` |
| 版本 | `$DEFAULT` | 跟随现网，重新部署函数后自动用新代码（新版界面才有这一项） |

## 三、最容易踩的坑：域名选错，小程序给的网址对不上

小程序 **我的 → 电脑端后台** 弹出的网址，是 `cloudfunctions/admin/lib.js` 里 `adminUrl()` 拼出来的：

```
https://cloud1-d9gca4e7q307c4564.service.tcloudbase.com/admin
```

而新版 HTTP 网关的默认域名长这样：

```
https://<环境ID>.<地域>.app.tcloudbase.com/admin
```

**两个域名不一样。** 小程序云开发环境早期开通的「云接入」默认域名就是 `<环境ID>.service.tcloudbase.com`；
新版控制台给的则是 `app.tcloudbase.com`。如果控制台只提供后者，配完虽然能用新地址打开后台，
但**小程序里复制出来的仍是旧地址、会继续报 404**。

所以按这个顺序处理：

1. 域名下拉里如果有 `cloud1-...4564.service.tcloudbase.com`，**优先选它**，一步到位
2. 如果没有，先把**控制台实际显示的完整链接抄下来**发我，
   我改 `lib.js`（或加 `ADMIN_BASE_URL` 环境变量）+ 重部署一次 `admin`，两边对齐
3. 目前 `adminUrl()` 只支持用环境变量 `ADMIN_ENV` 换环境 ID，**不支持换整段域名**

> 另一个小提示：`*.app.tcloudbase.com` 默认域名在浏览器直接打开时可能出现**安全提示中间页**，
> 点「继续访问」即可（开发测试阶段的限制，生产环境才需要绑定已备案的自定义域名）。

## 四、怎么确认成功

```bash
curl -s https://cloud1-d9gca4e7q307c4564.service.tcloudbase.com/admin | head -c 120
```

- 返回 `{"code":"INVALID_PATH"}` → 路由还没建好（或路径写错、开关没开），再等等
- 返回 `<!DOCTYPE html>` 之类 → **成功**，浏览器打开应该看到后台登录页

然后到小程序 **我的 → 电脑端后台**，复制弹窗里的账号和 6 位口令，在浏览器登录。
只有机构负责人/管理员能拿到口令（服务端按 `members` 表判角色）。

### 账号和口令怎么来的（`mkAccount`）

- **不用注册，也不用自己设**：第一次点「我的 → 电脑端后台」时，云函数 `admin` 的 `mkAccount`
  在服务端按机构生成一份，存进 `admin_accounts`（集合自动建）。弹窗会同时给出账号、6 位口令、网址，
  点「复制全部」直接粘到浏览器。
- **一个机构永远一份**：再点、换手机、换人接手，返回的都是同一份，口令不会刷新。
  口令丢了就再点一次看；云端虽然有 `resetPin`，但小程序端暂时没有入口。
- **点之前会先强制同步一轮**：服务端靠「`members` 表里有一条 `openid` 对得上、且
  `role` 是 `owner`/`admin`」判权限，刚建的机构若还没推上云，会白挨一个「没有权限」。
- **口令别发班级群**：错 5 次锁 10 分钟；登录换的 token 有效期 7 天。

**看不到入口 / 点开报错，按这个顺序查**：

| 现象 | 原因 / 怎么办 |
|---|---|
| 「我的」里根本没有「电脑端后台」 | 当前身份不是管理员（入口受 `db.auth.isAdmin()` 控制）。「切换身份」切回负责人；演示数据模式下也拿不到 |
| 提示「只有机构负责人/管理员能打开电脑端后台」(`FORBIDDEN`) | 云端 `members` 表里没有「openid = 你 + role = owner/admin」的那条。常见原因是成员行没绑上微信，或同一微信长出两条负责人（11-06 的重复绑定问题，**1125 体验版**已修）；先升级到 1125、点一次「立即同步」再试 |
| 提示「取账号失败 / 网络不通」 | `admin` 云函数没部署或网络异常：`npm run cloud -- admin` 重推一次 |
| 浏览器说「账号不存在」 | 还没在小程序点过那一下，服务端尚未生成 |

## 五、报错对照

| 现象 | 原因 / 怎么办 |
|---|---|
| `INVALID_PATH` | 路由没建、触发路径写成了 `/admin/`、`admin`；也可能刚建完还在生效（等 5 分钟） |
| 路由建好了仍然 `INVALID_PATH` | **顶部「HTTP 访问服务」全局开关没打开**，或选错了环境 |
| 腾讯云里看不到这个环境 | 登录方式不对：要用小程序管理员微信扫码 + 选中该小程序授权 |
| 打开是「后台页面缺失，请重新部署 admin 云函数」 | 云端函数里没读到 `public/index.html`；跑 `npm run cloud -- admin` 重新部署一次 |
| 页面空白 / 502 | 同上，或函数冷启动失败；看云函数日志 |
| 浏览器出现安全提示中间页 | 默认域名的开发测试限制，点继续访问即可 |
| 页面能开、登录说账号不存在 | 先在小程序点一次 **我的 → 电脑端后台**，服务端这时才生成账号和口令 |
| 小程序里复制的网址打不开，但控制台给的地址能开 | 就是第三节的域名不一致，把实际网址发我 |

## 六、为什么这一步只能人工点

- 微信开发者工具 CLI 的 `cloud functions` 只有 list / deploy / info / download，**没有路由或 service 命令**
- 腾讯云 `@cloudbase/cli` 有 `cloudbase service create -p /admin -f admin -e <env>`，
  但本机未安装，且要先装 CLI + 用腾讯云账号登录（密钥或扫码），为一条只配一次的路由引入密钥不划算
- 结论：**点一次，永久生效**，之后重新部署 `admin` 函数也不会丢路由

> 不配的后果只有一个：浏览器打不开电脑端后台。**小程序内所有功能不受影响**。
