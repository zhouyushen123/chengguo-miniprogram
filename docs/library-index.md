# 橙果课堂 · 课后成果记录小程序｜项目总览

> 这里是给协作者看的入口。**代码本体在 GitHub**，资料库里放的是能读、能评论、能一起改的文档
> 和一份源码快照。两边不会自动同步：改代码请去 GitHub，改文档或提意见可以直接在这里。

## 一、这个项目是什么

面向培训机构老师的微信小程序：按班级记录学生的课后成果（分数、评价标签、照片、语音、
家长留言），支持多老师 / 多机构共享、云端同步、家长端查看、电脑端后台管理。
技术形态是原生微信小程序 + 微信云开发，代码仓库：

https://github.com/zhouyushen123/chengguo-miniprogram

## 二、当前进度（2026-11-07）

- 功能面：V10 已成型，体验版 **1125**，云环境 7 个云函数全部在线
- 质量：29 个测试套件全绿，主包约 1.2 MB（上限 2 MB）
- 数据体检已在真机验证：跨机构骨架残留、重复绑定两类问题均已自动修复
- 卡点：小程序备案管局审核中，**还不能正式发布**；外人目前只能通过「体验成员」打开
- 剩余人工项见《待办清单》：两个数据库索引、电脑端后台 HTTP 路径、备案、真机确认

## 五、日常命令（开发用）

```bash
npm run check      # 门禁：lint + 结构文档 + 体积 + 全量测试，提交前必跑
npm run preview    # 生成预览二维码，扫码看当前代码
npm run ship       # 门禁 + 上传体验版，版本号自增
npm run cloud:ls   # 看云端函数与代码的差异
npm run cloud      # 串行部署云函数
```

## 六、三条提醒

1. **云环境是共享的生产库**：调试用演示模式，别在真机点「立即同步」。
2. **仓库是公开的**：不要把口令、密钥写进代码或文档。
3. **push 到 main 会触发 CI 自动上传开发版**：走分支 + PR，别直接推 main。
