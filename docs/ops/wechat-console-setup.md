## 1. 用户隐私保护指引（先做，要审核 1–2 天）

路径：**mp.weixin.qq.com** → 设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引 → 去完善

### 1.1 勾选需要收集的信息

勾这四项：

- ☑ **选中的照片或视频信息**
- ☑ **麦克风**
- ☑ **手机号**
- ☑ **设备信息**（微信基础库自动收集，用于安全风控；不勾会被驳回）

### 1.2 每一项的用途说明（直接粘贴）

**选中的照片或视频信息**
> 用于教师上传课堂照片或视频，作为学生课后成果记录的一部分，供本机构教师与家长查看。信息存储于微信云开发（腾讯云）存储空间，仅在账号存续期间保留；机构删除记录或用户注销账号后，将在 30 天内清除。

**麦克风**
> 用于教师录制课堂语音评语，语音经识别转为文字后由教师编辑确认，作为学生评价内容。音频文件存储于微信云开发（腾讯云）存储空间，仅在账号存续期间保留。

**手机号**
> 用于机构联系人、家长联系方式以及账号找回。手机号由用户主动填写，不通过任何接口自动获取，不用于营销推送，不向第三方共享。

**设备信息**
> 用于保障账号与数据安全、排查异常与故障。由微信基础库自动收集，本小程序不做额外留存。

### 1.3 其他必填项

- **信息保存期限**：账号存续期间；删除后 30 天内清除备份
- **第三方共享**：不向任何第三方共享（微信云开发与语音识别插件属受托处理，不视为对外共享）
- **用户权利**：可在「我的 → 存储空间」查看、导出与清除本机数据，或联系机构管理员删除
- **联系方式**：填你自己的常用邮箱（审核结果会发到这里）

提交后等审核。审核通过前，真机上点相册或录音会「没反应」——这是微信的强制拦截，不是程序 bug。

## 2. 数据库集合权限

路径：**云开发控制台** → 数据库 → 选中集合 → 右上「数据权限」

对下面每个集合都执行一次：

```
orgs, members, terms, classes, courses, subjects, knowledge_points,
students, enrollments, records, templates, backups, history
```

> `users` 只在本机（账号表不参与同步），云端没有这个集合，不用设。

选：**所有用户不可读写**（`{"read": false, "write": false}`）

> 为什么：小程序端从不直连数据库，全部走云函数（管理员权限）。关掉前端直连，
> 别人即使拿到 AppSecret 之外的手段也读不到你的库，也绕不过 syncv2 的机构校验。

## 3. 数据库索引

路径：**云开发控制台** → 数据库 → 选中集合 → 索引管理 → 新建索引

| 集合 | 索引名 | 字段（顺序不能反） | 唯一 |
| --- | --- | --- | --- |
| `records` | `org_srv` | `orgId` 升序 + `srvAt` 升序 | 否 |
| `students` | `org_srv` | `orgId` 升序 + `srvAt` 升序 | 否 |
| `classes` | `org_srv` | `orgId` 升序 + `srvAt` 升序 | 否 |
| `members` | `org_openid` | `orgId` 升序 + `openid` 升序 | 否 |
| `members` | `org_role` | `orgId` 升序 + `role` 升序 | 否 |
| `students` | `org_no` | `orgId` 升序 + `no` 升序 | 否 |

> 前三条是同步增量拉取（`orgId + srvAt > 游标`，按 srvAt 升序取 100 条）的形状；
> `org_openid` 用于身份认领与「一个微信只能绑一个成员」的校验；
> `org_role` 用于「机构只能有一个负责人」；`org_no` 用于学号查重。
> 现在零索引：几百条感觉不到，上千条后每次同步都是全集合扫描。
