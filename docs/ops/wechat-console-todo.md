# 微信侧还需要配置的东西（2026-11-05 夜）

> 只列「必须在微信公众平台 / 云开发控制台点，代码改不了」的事项。
> 上传体验版已经可以自动跑（`cli.bat upload`），不需要手动点。

## 必做（影响数据安全或真机能不能用）

### 1. 用户隐私保护指引 ★ 最要紧

路径：mp.weixin.qq.com → 设置 → 服务内容声明 → **用户隐私保护指引**

本项目实际用到的隐私接口：

| 接口 | 用在哪 | 声明项 |
| --- | --- | --- |
| `wx.chooseMedia` | 录入页拍照/录像、学生头像、批量导入 | 相册 / 摄像头 |
| `wx.getRecorderManager` | 课堂语音评语 | 麦克风 |
| 手机号输入 | 入驻、机构资料、人员、学生档案 | 手机号 |

不填的后果：真机上点相册/录音**没有任何反应**（新版微信强制拦截），而模拟器正常。
审核通常 1–2 个工作日。

### 2. 数据库集合权限

路径：云开发控制台 → 数据库 → 每个集合 → 数据权限

建议：**所有用户不可读写**（`{"read": false, "write": false}`）。
理由：小程序端从不直连数据库，全部走云函数（管理员权限）；关掉前端直连，
别人拿不到你的库，也绕不过 syncv2 的机构校验。

### 3. 数据库索引

路径：云开发控制台 → 数据库 → 集合 → 索引管理

| 集合 | 字段 | 说明 |
| --- | --- | --- |
| `records` | `orgId`(升) + `srvAt`(升) | 同步增量拉取的主查询 |
| `students` | `orgId`(升) + `srvAt`(升) | 同上 |
| `members` | `orgId`(升) + `openid`(升) | 认领/身份查询 |

现在**零索引**：数据量小感觉不到，上千条后每次同步都是全集合扫描。

### 4. 体验成员

路径：mp.weixin.qq.com → 管理 → 成员管理 → **体验成员**

把要用的老师/家长微信加进去，否则他们打不开体验版。

## 可选（等功能上线再做）

### 5. 家长订阅消息

需要先在公众平台申请订阅消息模板，再把模板 ID 配到 `family` 云函数的环境变量
`NOTIFY_TEMPLATE_ID`。没配时全家链路静默降级（不报错、只是不发通知）。

### 6. 网页版后台（admin）

`cloudfunctions/admin` 目前没有 `config.json`（没配 HTTP 访问服务），
所以「数据安全」那套网页后台要先开通：

云开发控制台 → 环境 → **HTTP 访问服务** → 添加路径 `/admin` → 指向 `admin` 云函数。

### 7. 服务器域名：不需要

小程序端只调云函数与云存储，不发第三方请求；AI 评语在云函数里出网，
不受「request 合法域名」限制。
