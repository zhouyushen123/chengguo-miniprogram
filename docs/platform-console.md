# 平台控制台（跨机构总览）

> 给运营/我们自己看的后台：一次看到**所有**在跑的机构、老师和学生。
> 和机构后台（`/admin`）的区别：机构后台一个账号只看一个机构、可以改数据；
> 平台控制台看全部机构、**只能看不能改**。

## 网址

```
https://cloud1-d9gca4e7q307c4564.service.tcloudbase.com/admin?view=platform
```

和机构后台同一个域名，只是多了 `?view=platform`。收藏这一条即可。

## 第一次使用：配平台口令（1 分钟，只需一次）

平台账号**不走**小程序生成（机构负责人无权给自己发"能看全部机构"的账号），
口令只存在云函数环境变量里：

1. 微信开发者工具 → 云开发控制台 → 云函数 → `admin` → 函数配置
2. 环境变量 → 添加：`PLATFORM_PIN` = 你定的口令（**6 位以上**）
3. （可选）`PLATFORM_ACCOUNT` = 平台账号名，默认 `CGPLAT`
4. 保存，等 1~2 分钟状态回到 Active

没配 `PLATFORM_PIN` 时平台登录是关闭的（返回 `NO_ENV`），不会有默认口令。
连错 5 次锁 10 分钟（和机构后台同一套节奏）。换口令：控制台改环境变量即可，即时生效。

## 能看什么

| 页签 | 内容 |
|---|---|
| 全局总览 | 机构/学生/老师/家长/记录/发布率六张卡；近 30 天全平台录入趋势（含已发布线）；机构规模排行；成绩五档分布与老师等级用法；运营提醒（空机构、两周没动静、草稿积压、抽样提示） |
| 机构清单 | 每家机构一行：负责人、学生/班级/记录数、发布率、每生记录数、最近上课、老师/家长数；点行进详情抽屉（该机构的 KPI、趋势、班级、成员、全部学生）；可导出机构清单 CSV |
| 学生总览 | 跨机构学生表：姓名/学号/机构/班级/记录数/最近记录/家长联系方式；按姓名搜、按机构筛、分页；可导出全平台学生 CSV |

统计口径：趋势按**上课日期**（不是录入时间）；发布率 = 已发布/总记录；
每生记录数低于 1 的机构 = 建了档但基本没在用。

## 技术备忘（改代码前读）

- 后端全在 `cloudfunctions/admin/`：`platform.js`（纯函数，可本地测）+ `index.js`
  里 `doPlatformLogin` / `platOverview` / `platOrgs` / `platOrg` / `platStudents` / `platExport`。
- 平台会话存在 `admin_sessions`，`scope: 'platform'`；`api()` 里与机构会话分叉，
  **default 一律拒**（`READONLY`）——写接口对平台会话不可达，`tests/verify_platform.js` 钉死。
- 跨机构统计优先用云数据库 aggregate（`countByOrg` / `trend30` / `maxDateByOrg`），
  失败自动退化为扫描并给 `sampled` 标记；分布类指标用最近 1000 条记录采样，界面会注明。
- 前端 `public/platform.html` 单文件、无依赖；`file://` 直接打开或带 `?demo=1`
  自动进演示模式（内置 5 家机构/约 200 名学生的假数据），部署后同一文件读真实数据。
- 部署：`npm run cloud -- admin`。HTTP 路由 `/admin` 已配好，`?view=platform` 走同一个函数。
