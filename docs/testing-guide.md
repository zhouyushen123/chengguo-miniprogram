# 橙果课堂 · 自动测试环境指南

> 更新：2026-11-09 ｜ 配套：`docs/user-test-cases.md`（247 条人工用例）
> 一句话：**改完代码先 `npm test`，动了页面流程再跑角色与冒烟，发布前跑 `npm run check`。**

## 一、三层测试体系

| 层 | 入口 | 靠什么跑 | 覆盖什么 | 什么时候跑 |
|---|---|---|---|---|
| L1 回归套件（47 个） | `npm test` | Node 直接跑 `tests/verify_*.js`，数据层用内存假 `wx.storage` | 迁移/权限/学期/备份/同步/页面源码纪律…每类功能一个套件 | 每次提交前（CI 卡点） |
| L2 角色旅程（4 个） | `npm run test:roles` | 同 L1，但按「一个角色从头用到尾」串场景 | 用户旅程 + 负责人 + 老师 + 家长，每段标注人工用例编号 | 改权限/角色/可见范围后必跑 |
| L3 真模拟器冒烟 | `npm run test:e2e` | miniprogram-automator 连微信开发者工具（`--auto-port 9420`） | 真页面渲染：向导四步 → 首页统计 → 录入发布 → 修改 | 发布体验版前 |

## 二、角色深度测试（L2）

一个角色一个套件，场景从搭环境到收尾按真实使用顺序走，失败时先看它再复现人工用例：

| 套件 | 主角 | 覆盖（括号 = user-test-cases.md 编号） |
|---|---|---|
| `verify_journey.js` | 全链路 | 开通四步 → 首页统计 → 录入发布 → 家长/老师视角 → 回收站 → 备份恢复（A/B/H/I/J/N/P/Q/R 抽样） |
| `verify_owner.js` | 机构负责人 | 身份与全量能力（O-04）、成员管理加改删恢复（G-02/04/06/08/09）、切换视角与切回（G-10/11）、学期结转计划与归档保护（K-03/04/08）、回收站四分类（N-02/04）、负责人唯一性防线 |
| `verify_teacher.js` | 老师 | 管理入口全拦（R-01）、只见自己班（R-02/05）、录入发布（R-03）、只改自己的（R-04）、无班老师 fail-closed、越界检查 |
| `verify_parent.js` | 家长 | 只读能力清单（Q-08）、只见自己孩子（Q-04）、只见已发布（Q-05）、历史倒序（Q-06/07）、一号多孩（Q-09）、家长版我的页裁剪（O-13） |

## 三、怎么跑

```bash
npm test              # 全部 L1+L2（约 1~2 分钟），退出码非 0 = 有失败
npm run test:roles    # 只跑 4 个角色旅程，改角色逻辑后快速验证
npm run test:e2e      # 先关掉已打开的微信开发者工具窗口，再跑（automator 要自己拉起）
npm run check         # lint + 数据字典 + 体积 + 全部测试，发布前最后一道
```

跑单个套件：`node tests/verify_perm.js`。

## 四、怎么加新用例（约定）

1. **修一个 bug 就守一个回归**：在对应功能的 `verify_*.js` 里加断言，或新建 `verify_<主题>.js` 并注册进 `tests/run.js` 的 SUITES 列表（注明套件名与一句话说明）。
2. **新功能先补人工用例**：按既有格式加进 `docs/user-test-cases.md`（编号 + 怎么点 + 预期），汇总表同步加行、改合计；能自动化的部分在 `tests/` 里补守卫，并在用例表注明。
3. **角色相关改动**：把场景加进对应角色的旅程套件（L2），别只写在单点套件里——单点绿但旅程断，通常就是权限范围漏了。
4. **测试数据**：内存假库即用即弃，不要依赖外部状态；页面源码级断言用「读源文件 + 正则」的方式（参考 `verify_owner.js` 的 O7）。

## 五、已知边界

- automator 拿不到小程序内的 `require`，清库要走存储页两道确认弹窗，自动化环境点不了 → L3 只走「只加不删」的流，清库/重置类用例（P-12/P-13）留给人工。
- 摄像头/麦克风/双微信对戏（H-08~H-14、G 组双微信前置、Q 组专属卡）是真机特性，由人工用例覆盖；数据层边界（绑卡一次性、作废重发）已有 `verify_invite_card.js` 等套件守住。
- 云端相关（同步上云、平台控制台）用内存假云函数库真跑（`verify_multi_org.js` / `verify_invite_card.js` / `verify_platform.js`），不依赖真实云环境。
