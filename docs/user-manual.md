## 0. 先看这一页

### 0.1 三种角色，看到的界面不一样

| 角色 | 能做什么 | 看不到什么 |
|---|---|---|
| 负责人 / 管理员 | 全部功能：机构资料、班级、课程、学生、人员、学期、所有记录 | — |
| 老师 | 录成果、改自己录的记录、看自己带的班级和学生 | 机构资料、人员管理、学期结转、别人的班和记录 |
| 家长 | 只看自己孩子**已发布**的记录、完整档案 | 别的孩子、未发布的内容、任何修改入口 |

角色由「负责人」在 人员 页分配，不是自己在界面上切。

### 0.2 五个名词

- **机构**：你的工作室 / 学校，一个机构一个空间，数据互相隔离。
- **学期**：一期课程（如「2026 秋季学期」），班级挂在学期下。
- **班级**：学生上课的组织单位，记录按班级归档。
- **课程**：教什么（书法、素描）。独立内容库，一门课可开在多个班，用于统计与筛选。
- **成果记录**：一条「某学生某节课的表现」——分数 + 评价 + 照片/语音，这是产品的核心产物。

### 0.3 底部三个页签

**首页**（干活的地方）· **记录**（查东西的地方）· **我的**（设置的地方）。所有功能都从这三个页签进。

## 1. 第一次打开：开通机构（4 步）

**入口**：微信打开小程序 → 首页中间显示「先花一分钟把机构建起来」→ 点 **开始开通**。

> 只想先看看：点首页下方小字「**先看看示例数据 ›**」。示例数据是样板间，能翻不能改，
> 顶部会有橙色横幅「演示数据 · 只看不改」，点横幅上的「**开始使用**」回到真实数据。

### 第 1 步：机构信息（标题「你的机构叫什么？」）

| 字段 | 怎么填 | 规则 |
|---|---|---|
| 机构名称 | 如「墨白书法工作室」 | 必填，2 字以上 |
| 机构类型 | 点一下选：培训机构 / 学校 / 幼儿园 / 个人工作室 | 默认「培训机构」 |
| 联系人 | 你的姓名 | 必填 |
| 手机号 | 直接输 11 位数字 | 必须 1 开头、共 11 位；**输满会自动变成 138-0000-0000 的样子**，这是正常的；输错底部会提示「手机号需 11 位、1 开头」 |

填完点底部 **下一步**。

> 如果弹出「**本机数据已修复**」：点确定继续就好。这是小程序发现本机身份记录损坏后
> 自动重建了一条负责人身份，不是报错，数据不会丢。

### 第 2 步：本学期（标题「这一期课程什么时候开始？」）

| 字段 | 说明 |
|---|---|
| 学期名称 | 已按当前月份预填（如「2026 秋季学期」），可改 |
| 开始日期 / 结束日期 | 点一下选日期，可留空 |

点 **下一步**。

### 第 3 步：先建一个班（标题「先建一个班」）

| 字段 | 说明 |
|---|---|
| 班级名称 | 如「书法提高班」 |
| 第一门课程 | 默认跟班级同名，可改（如「软笔书法」） |
| 上课方式 | **学期制**：按学期算，不扣课时<br>**课时结转**：按课时算，每录一条记录自动扣 1 课时 |

点 **下一步**。

### 第 4 步：把学生加进来（标题「把学生加进来」）

1. 在「学生姓名」输入框填名字（如「李思远」）
2. 点右侧 **添加**，名字出现在下方列表
3. 继续填下一个，可一次加多个
4. 全部加完点 **下一步**

> 学号由系统自动生成（如 1001），家长以后用学号绑定孩子，不用你自己编号。

### 完成页（标题「已经可以开始记录了」）

会列出刚建好的 **机构 / 学期 / 班级 / 学生** 四项，三个按钮：

- **录入第一条成果** → 直接进录入页
- **先去首页看看** → 回首页
- **去「管理」补全信息** → 补手机号、地址、课程方向等

不想现在填也能退出：底部小字「**稍后再说，先进去看看**」。

> 已经有机构了（别人邀请你）：在向导页点底部「**我有邀请码，用邀请码加入机构 ›**」，
> 输入老师给的 6 位机构码 → 输姓名 → 老师/家长按提示完成。

## 2. 首页

从上往下的顺序：

| 区域 | 内容 | 点它会怎样 |
|---|---|---|
| 顶部标题栏 | 机构名称 + 今天日期 | — |
| 大卡 | **开始录入** / 选学生 · 打分 · 发家长 | 进录入页 |
| 第二张卡 | **全部记录** / 按学生查看 | 进记录列表 |
| 三个数字卡 | **班级 ›** / **学生 ›** / **本次未录入 ›** | 前两个直达管理页对应页签；「本次未录入」进记录列表 |
| 我的班级 | 每个班一张小卡（班名、人数、本次已录/未录） | 进该班班级详情页 |
| 最近成果 | 最近几条记录（学生名、分数、一句评语） | 点某条看详情；点右上「全部」进记录列表 |
| 搜索框 | 输姓名/学号/家长名 | 显示匹配结果，点结果进学生档案 |

**顶部横幅（只在异常时出现）**

- 橙色「**演示数据 · 只看不改**」→ 点「开始使用」正式使用
- 「**这台手机的数据没和云端同步**」→ 点「怎么办」看说明（通常是换手机前后各建了一份机构）

## 3. 管理页：机构 / 班级 / 课程 / 学生 / 人员

**入口**：首页点「班级 ›」或「学生 ›」直达对应页签；首页「我的班级」标题右侧 **管理**；
或 我的 → 设置 → 开通引导。负责人看到 5 个页签：**机构 · 班级 · 课程 · 学生 · 人员**，老师只看到前三个中的 **班级 · 课程 · 学生**。

### 3.1 机构

填/改：机构名称、机构类型、所在地区、联系人、手机号、学员规模、课程方向（可多选）。
点底部 **保存机构资料**。手机号规则同向导（11 位、1 开头、自动分段）。

### 3.2 班级

**新建班级**：点 **＋ 添加班级** → 填

| 字段 | 说明 |
|---|---|
| 班级名称 | 必填 |
| 学期 | 下拉选，默认当前学期 |
| 学期制 / 课时结转 | 决定是否扣课时 |
| 主讲老师 | 下拉选，可留空 |

点 **添加**。

**看班里学生**：点班级卡片展开 → 显示本班学生名单，可筛选（输入姓名/家长）。
卡片下方 **＋ 添加学生到本班**：从已有学生里勾选加入本班。

**删除班级**：卡片右侧 **删除** → 二次确认。删班同时删掉本班报名（课时账），
学生和记录保留，可在回收站恢复。

### 3.3 课程

课程是**独立的内容库**，不再"属于"某个班级：一门课（如「楷书」）只存一条，可以同时开在书法班、提高班、集训班。

**添加课程**：点 **＋ 添加课程** → 填课程名称 → 填 **课程介绍**（选填，可点麦克风说出来，最多 500 字）→ 在「开设到」里**勾选班级（可多选）** → 点 **添加课程**。
一门课可以同时开给一班到六班甚至更多；一个班都不勾就是先放进课程库，之后随时开到班。
若课程库里已有同名的课，系统直接复用它开到勾选的班，不会建出第二条（会提示「已直接开设」）。

每个课程条目显示它开设的班级和一行介绍摘要：

- 点班级小标签 **×** = 取消这个班的开设。**只影响这个班**，课程本身和其他班不变，历史记录也不受影响。
- 点 **＋ 开设到…** = 弹出**全部班级**的勾选框，一次勾几个班就一次开到几个班；已经开设的默认选中，取消勾选 = 从该班撤下。不再需要一个个班重复点，也没有「最多 6 个班」的限制。弹层里还能 **全选 / 清空**。
- **详情**：编辑这门课的课程介绍（介绍是课程本体，改它不动班级开设关系，也不动历史记录）。
- **改名**：课程名改了，历史记录上的旧课程名照旧保留。
- **删除**：课程进回收站（可恢复），它在所有班的开设一起撤下。
- **同名课程合并**：课程库出现多条同名课（老数据「一个班建一条」留下的）时，列表上方会出现提示卡，点 **一键合并同名课程** 收拢成一条——各班开设、成果记录的课程指针、成员课程授权一起转到留下的那条，记录里显示的课程名不变。合并掉的副本不会出现在回收站，也不能还原（否则又变回重复项）。

> 为什么这样设计：一门课只维护一份，将来题目、教案、作业挂在课程上就能所有班共用；以前每班一条课，改一次要改好几遍。

**课程还有哪些字段**：目前每门课存的是「名称 + 学科 + 课程介绍 + 扩展槽」。扩展槽是给以后留的位置，
再加 *适合年龄、总课时、教材版本、教学目标、上课形式、封面图、课程大纲、标签* 这类内容时，
不用改表结构、不用迁移历史数据、也不用重新部署云函数（同步按整行透传）。
要真正在界面上填某个字段，才需要给管理页加输入框；字段定义以
`docs/data-dictionary.md`（由 `utils/db/entities.js` 自动生成）为准。

### 3.4 学生

**搜索**：顶部搜索框输姓名 / 学号 / 家长名。
**筛选**：入学年份、性别两个下拉。

**添加学生**：点 **＋ 添加学生** →

| 字段 | 说明 |
|---|---|
| 学生姓名 | 必填 |
| 学号 | 保存后自动生成；保存后点学号可复制 |
| 性别 | 点选，再点一次取消 |
| 入学年份 | 下拉选 |
| 加入班级 | 可多选，决定这个孩子出现在哪些班 |
| 家长手机号 | 选填，11 位、1 开头；输满自动显示成 `138-0000-0000`，落库只存裸数字。格式化字段没有麦克风，直接打字 |
| 家长称呼 | 如「张珊珊/妈妈」 |
| 家长微信号 | 方便沟通 |
| 照片 | 点头像位拍照或从相册选，也可用微信头像。保存后**学生列表、班级展开名单、档案页的头像都会变成这张照片**，退出重进仍然在 |

手机号和微信号都是「同一位家长」的识别依据：新孩子填了和老大相同的手机号（或微信号），会自动归到同一个家长账号下。只填其中任意一个也能归并，老数据只填了微信号的一样有效。

**发家长邀请卡（免记码，推荐）**：在学生列表里点这个学生的「**发卡**」→ 弹层里先看清卡面写了谁 →
点「**发给家长**」把这卡片微信转发给这一位家长。卡上只有孩子姓名、机构、班级，**没有学号、
手机号、成绩和照片**；家长点开后填自己姓名、点一次「我是，确认加入」就进来了，不用记 6 位机构码，
也不用记孩子学号。卡片 **7 天有效、只能确认一次**，老师可点「作废重发」让旧链接立即失效。

> 第一次发卡会先自动同步一轮：云端要先看到这个学生和你的成员身份，才发得出卡。
> 刚录完学生立刻点，若提示「云端还没有这个学生」，等半分钟再试一次。
>
> **本阶段请单独私聊发给这一位家长，不要发到班级群**：整班群发卡和「老师审核」还在下一批
> （见 `docs/invite-card-plan.md` 阶段 2）。群里谁都能点开卡片，没有审核就可能点错孩子。

点 **保存**。若同一家长号码下已有孩子，会提示「已保存，已归入家长 ××」——系统自动把
新孩子接到同一个家长账号，家长不用重复绑定。

**编辑 / 删除**：列表每行右侧 **编辑** 打开同一张表单；**删除** 是软删除，进回收站。

**批量导入**：点 **批量导入** 进导入页（见第 9 章）。

### 3.5 人员（仅负责人）

三个分类：**全部 / 老师 / 家长**。

**添加老师**：点 **＋ 添加老师** → 姓名、手机号（选填）、微信号（选填）、角色、
负责班级（可多选，至少一个）、课程权限（不选 = 所带班级全部课程）→ **保存**。
老师登录后只能看到分配给自己的班级与学生。

**添加家长**：点 **＋ 添加家长** → 填姓名 → 在「关联孩子」里**直接点孩子名字**（不用背学号）；
学生多时用搜索框搜姓名 / 学号 / 家长，点一下即绑定，可绑多个孩子 → **保存**。
「按学号快捷绑定」仍保留，记得号码时输完点「添加」更快。同一个家长号码下的孩子会自动带出。

**其他操作**：成员行右侧 **修改**（改姓名、手机号、微信号、头像、角色与负责班级 / 关联孩子，
一次全改完）、**移除**（软删除，进回收站）；
列表上方可「**切换**」到某个成员视角看效果，再用顶部「**切回我自己**」回来。
成员说明文字很长时会自动省略，右侧这几个按钮始终在同一行，不会换行。

## 4. 录入一条成果（核心功能）

**入口**：首页 **开始录入**；或班级详情页点学生；或学生档案页 **记录本节成果**。

页面自上而下 6 块，逐块填：

### 4.1 选择学生

点学生名字选中（选中会高亮）。班内人多时用搜索框；名单超过 45 人会折叠，点「展开全部」。

> 从班级详情页进来时，学生已自动带入，可跳过这步。

### 4.2 课堂评分

拖动滑杆（0–100，默认 85），或直接点下面的档位标签：

| 档位 | 对应分数 |
|---|---|
| 待提高 | 60 |
| 加油 | 75 |
| 良好 | 85 |
| 优秀 | 92 |
| 最佳 | 98 |

### 4.3 课程

下拉选这节课属于哪门课（默认本班第一门）。课程会影响记录的统计归类。

### 4.4 归入课次

只有这个班已经结清过课次时才会出现，默认「第 1 次课」。补录旧课时改这里。

### 4.5 课堂成果（照片 / 视频 / 语音）

- **拍摄**：调相机拍一张（可连续拍）
- **相册**：从相册选（可多选）
- **语音**：点麦克风开始说，再点结束，**单条最长 60 秒**；会自动转成文字填进评价框，可手改
- 每张照片/视频右上角有删除角标，点掉即可移除；点图片可放大预览

### 4.6 课堂评价

三种录入方式：

1. **手写**：直接在评价框输入
2. **模板**：点「模板」→ 弹出模板面板 → 点选项多选 → 点 **插入所选**（一次写入多条）
   - 面板里可 **＋ 新增选项**、**编辑**、**删除**、**清空选择**
3. **AI 评**：点「AI 评」→ 先出现一块「让 AI 按你的要求写」→ 勾重点、说一句 → 点「生成评价」
   - **重点看什么**（可多选）：专业技法 / 画面与结构 / 课堂状态 / 和上次比 / 情绪与状态。
     勾过的会被记住，下节课默认还勾着，不用每次重选
   - **再跟 AI 说一句**（选填）：直接写或按麦克风说，例如「重点夸构图，他这学期线条进步很大」。
     这是你唯一能直接指挥 AI 的地方，写得越具体，出来的越像你本人写的
   - **什么都不勾也能生成**：系统已经自动带上孩子姓名、课程、学科评价维度、上一次的评语
   - 生成的内容是草稿：框里已有字时会先问要不要覆盖；发出前一定过一眼
   - AI 没照片就不会编，所以**先拍照再用 AI 评**，结果才具体

### 4.7 预览与发布

底部三行：

| 按钮 | 作用 |
|---|---|
| **预览效果** | 打开**家长视角成果卡**：孩子头像姓名、班级 / 课程 / 日期、分数与档位、老师评语全文、照片（可点开）、视频与语音（可播放）。卡片下方另附可复制的通知文本 |

## 9. 批量录入与批量导入

### 9.1 批量录入（一节课给全班打分）

**入口**：班级详情页底部 **成绩单批量录入本次课**。

1. 填「本课主题」（选填；AI 写评语时会围绕这个主题）

6. 全部填完点 **保存** → 确认

> 有内容没过内容安全检查时会标「未过安全检查」，需要改掉那部分再保存。

#### 本课照片（一次上传整节课的照片，分给对应学生）

一节课拍的照片不用逐个学生进去传：在批量录入页顶部「**本次课照片**」一次拍一张或从相册**一次选多张**（一次最多 9 张、整节课最多 30 张），照片进「照片池」，然后两种分法：

- **点照片**：弹出全班名单，勾这张照片要给哪些同学（作品照、单人展示常用）。
- **点学生行的「+ 选照片」**：弹出照片池，勾这位同学要哪几张（一人多张常用）。
- 缩略图角标显示「N 人」或「待分配」；**长按看大图**，右上角 × 删掉（同时从所有同学那里撤掉）。
- 合影 / 板书可以打开「**全班共用这些照片**」，自动加到每位同学的记录里；个人专属照片会一起带上。

**每人最多 9 张**（与单人录入同一口径），超出的保存时只取前 9 张并在确认框里提示。
**没分给任何人的照片不会出现在任何记录里**，确认框会提醒还有几张没分。

保存后照片在后台统一上云：同一张照片**只上传一次**、只过一次内容安全，再回填到全班记录；上传慢不会挡住保存，失败保留本地照片，下次进首页自动补传。不选照片时整条流程和以前完全一样；录到一半退出，照片池和分配关系会跟着草稿一起恢复。

**结清本次课**（班级详情页成绩单入口下方）：只有本次课**至少录了 1 条成果**时才出现。
本次课一条没录时这里只显示一行淡字提示，不会把空课次推进到下一课；下方「班级记录」
里全是往期课次的历史记录，也不算本次录了。

## 12. 存储与数据安全

**入口**：我的 → 设置 → **存储空间**。这一页是「数据体检站」，建议每周看一眼。

| 卡片 | 显示什么 | 能做什么 |
|---|---|---|
| 设备存储 | 学生 / 班级 / 课堂记录 / 照片视频 的占用 | 看「可清理」提示 |
| 回收站 | 最近删除的条数 | 查看并恢复 |
| 云同步 | 待推送条数、上次同步时间、失败原因 | **立即同步**；失败条目可「知道了，隐藏」 |
| 数据体检 | 两层：① 人/班/机构的记录对不对 ② 它们之间的连线有没有指着空数据 | **修复可自动处理的问题**、**修复断线** |
| 本地备份 | 最近一次快照时间 | **立即备份** / **从备份恢复** |
| 云端备份 | 今天是否有清单 | 立即跑一次云端备份 |
| 本机数据 | 各表有效条数（学生/班级/记录…） | **重置本机数据**（危险，见下） |

### 12.1 正常状态是什么样

- 云同步：**0 条待推送**，最近同步时间是刚才
- 数据体检：右上角写「一切正常」，下面没有红字清单
- 本机数据：学生、班级、记录的数字与你实际录入的一致

**看到「待同步」不用管。** 数据体检里标着「待同步」的那几行，意思是这台手机还没收到那条数据——
通常出现在换手机、重装、或很久没联网之后。右上角写的是「正常（N 处待同步）」，不是故障；
去云同步点一次「立即同步」就会自己消失。

**只有红字才是要处理的。** 红字表示某个班开设的课、或某条记录指向的班级/学生已经不存在了。
点 **修复断线**：它只会摘掉「指向已删除数据」的引用（比如课删了，班里的开设记录一起撤下），
不会删学生、不会删记录、不会删课。摘完如果还有红字，把它截图发我们。

### 12.2 怎么同步

一般不用管：每次保存后几秒内自动推送到云端，失败会自动重试 3 次（30/60/120 秒）。
需要手动推一把：云同步卡 → **立即同步**。

### 12.3 备份怎么用

- **立即备份**：把当前数据在本机存一份快照（防手机坏、误操作）
- **从备份恢复**：回到快照那一刻的数据（会覆盖当前本机数据）
- **云端备份**：负责人每天第一次打开小程序时自动跑一次，可在本机看到今天的清单

### 12.4 什么时候用「重置本机数据」

只在一种情况下用：**数据彻底乱掉、开通向导也过不去**。

- 会清空这台手机上的数据，回到出厂状态，然后从云端拉回
- 有业务数据时**先备份**（本地备份卡）
- 需要连续确认两次才执行

> 正常使用**不要点它**。卡在「请先登录」时：先重走开通向导（会自动修复身份），
> 修不好再回来重置。

## 13. 家长端

家长看到的首页和老师不一样：没有录入、没有管理，只有孩子的成果。

| 区域 | 内容 |
|---|---|
| 孩子切换 | 有多个孩子时顶部可切换 |
| 孩子卡片 | 姓名、班级、最近一次分数 |
| 最近一次 | 分数、等级、照片（可点开放大）、语音（可播放）、老师评语 |

| 完整档案 | 孩子的资料页（学校、年级等老师填的字段） |

家长**看不到**：别人家孩子、未发布的记录、任何修改按钮。

**已读回执**：家长真正点开某条成果的详情（从首页最近成果点进去、或在档案里展开某次课），
老师端那条记录就会显示「**家长已看**」；只进首页看摘要不算，收到微信提醒也不算。
这样老师看到的是真实反馈，不是一片假已读。

**给老师留句话**：成果详情底部点「给老师留句话」→ 写一句（也可以点麦克风说出来）→ 发给老师。
同一张成果最多 3 条、一分钟内最多 2 条，防误触刷屏；写完在下面能看到自己说过的话和
「**已送达，等老师看** / **老师已看**」状态。这段话只有本班老师能看到。

**家长怎么进来（推荐 · 一人一卡）**：老师在管理页学生列表点「发卡」，把写着孩子姓名的卡片
微信发给你 → 点开 → 填自己的姓名 → 点「我是，确认加入」→ 完成。**不用记机构码，不用记学号。**
卡面只写孩子姓名、机构、班级；7 天有效、只能确认一次，老师可作废重发。
同一个家长号码下的兄弟姐妹会自动一起带上，不必逐个加入。

**老入口仍然可用**：老师给 6 位机构码 → 打开小程序点「我有邀请码」→ 输码 → 输姓名 →
选「我是家长」→ 输孩子学号认领 → 完成。已经发出去的机构码不会失效。

家长**本机已经有数据**时（比如之前建过自己的机构），确认页会先提示到
「我的 → 设置 → 存储空间」清空，别填完姓名才报错。之后老师发新记录，家长打开就能看到。

| 首页（自己班的统计、最近成果） | 机构页签、人员页签 |
| 管理页：班级 / 课程 / 学生（限自己带的班） | 学期管理与结转 |
| 录入、修改自己录的记录 | 改别人的记录 |
| 存储空间 | 电脑端后台、邀请成员 |

**老师怎么进来**：负责人给 6 位机构码 → 打开小程序 → 「我有邀请码」→ 输码 → 输姓名 →
选「我是老师」→ 完成。负责人记得在 人员 页给他分配班级，否则他看不到学生。

**家长反馈（已读 + 留言）**：老师看得到「谁看了、谁还没看」，也看得到家长说了什么。

| 在哪 | 看到什么 |
|---|---|
| 首页 | 「家长反馈」入口，有待处理留言时右上角亮数字 |
| 记录页 | 每条**已发布**记录下面标「家长已看 / 家长未看」，有留言再标「留言 N」 |
| 班级页 | 本次课「家长已看 x/y」，点进去就是该班的反馈列表 |
| 家长反馈页 | 留言列表：孩子 · 班级 · 课程日期 · 原话 · 时间；未处理置顶，可「标记已处理」 |

只统计**已发布**的记录（没发布的家长本来也看不到）；老师自己打开记录不算家长已读。
一期不推微信通知给老师，靠进小程序的数字提醒；家长端能立刻看到「老师已看」。

## 15. 常见问题

**Q1 点「下一步」弹「请先登录」**
本机的身份记录坏了。新版本会自动修复并重试，正常情况弹一下「本机数据已修复」就过去了。
如果反复出现：我的 → 设置 → 存储空间 → 本机数据 → **重置本机数据**（先做本地备份），
重置后重走开通向导，云端记录会自动拉回。

**Q2 手机号输到第 10 位就输不进了**
这是老版本的 bug，1112 之后已修。确认版本：我的 → 设置 → 关于橙果。仍复现就把现象截图反馈。

**Q3 手机上录了，云端看不到**
先看 存储空间 → 云同步 的「待推送」数：
- 显示 0 条：已经推上去了，去云开发控制台刷新看
- 显示 N 条并带失败原因：点「立即同步」重试；持续失败的把原因截图反馈

**Q4 家长看不到刚发的记录**
① 确认点的是「发布到家长端」不是「存草稿」；② 家长要绑定孩子（点名字即可，不必背学号）；
③ 家长下拉刷新首页。

**Q5 换手机后数据没了**
新手机登录后会自动从云端拉取。如果拉不到，看首页是否有「这台手机的数据没和云端同步」横幅，
点「怎么办」按提示处理（通常是两台设备各建了一份机构）。

**Q6 班级删错了**
我的 → 设置 → 存储空间 → 回收站 → 班级 → 找到它 → **恢复**。

**Q7 课时数不对**
只有「课时结转」制班级才扣课时，每录一条记录扣 1 课时；学期制班级不扣。
要调整：管理页 → 班级 → 点开班级看报名与剩余课时。

**Q8 想把记录发给家长微信**
录入页 → **预览效果** → 卡片下方 **一键复制，发给家长**，粘贴到微信即可。

**Q9 电脑上想批量改评语**
我的 → 机构与身份 → 电脑端后台 → 复制账号/口令/网址 → 浏览器登录。

**Q10 界面颜色不喜欢**
我的 → 设置 → 外观 → 点色块，立即生效。

**Q11 家长说看了，但我这儿还是「家长未看」**
① 只有**已发布**的记录才会有回执；② 家长要真正点开那条成果的详情（进首页看摘要不算）；
③ 家长下拉刷新后再打开一次；④ 刚点开时云端写入有几秒延迟，下拉刷新记录页即可。

**Q12 家长留言在哪里看**
首页「家长反馈」（有数字）、记录页的「留言 N」小标、班级页本次课的「家长已看 x/y」
都能进去。处理完点「标记已处理」，家长那边就会显示「老师已看」。
