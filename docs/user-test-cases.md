# 橙果课堂 · 机构用户测试用例（细化到功能点）

> 版本：体验版 1114+ ｜ 更新：2026-11-06
> 每条用例 = 一个功能点，格式为「怎么点 → 应该看到什么」。
> **判定口径**：预期全部满足 = 通过 ✓；有一条不满足 = 不通过 ✗，截图并注明用例编号（如 `H-07`）。

## 一、怎么用这份清单

### 1.1 测试前准备（约 5 分钟）

| 项 | 要求 |
|---|---|
| 手机 | 一台主力机，微信已登录，**已加入体验成员** |
| 版本 | 「小程序助手」→ 橙果 → 选「体验版」进入；我的 → 关于橙果 核对版本号 ≥ 1114 |
| 数据 | 允许清空测试数据（建议用测试机构，不要用真实在用的机构） |
| 账号 | 准备 2 个微信：A = 负责人，B = 老师或家长（测权限与家长端） |
| 素材 | 相册里放 2 张图片、1 段 5 秒视频；准备一份学生名单表格（测导入，可选） |
| 网络 | 全程保持联网；`P` 组用例需要开关飞行模式 |

### 1.2 记录方式

建议把本文档复制到腾讯文档/表格，加一列「结果」填 ✓ / ✗ / —（不适用），
✗ 的那一行把截图贴在下面。

### 1.3 优先级

| 级别 | 含义 | 处理方式 |
|---|---|---|
| **P0** | 阻断级：白屏、进不去、数据丢失、越权 | 任何一条 ✗ 就不能给机构用 |
| **P1** | 核心链路：开通、录入、发布、修改、同步 | 必须全过 |
| **P2** | 体验细节：文案、排序、筛选、空态 | 可带到下一版 |
