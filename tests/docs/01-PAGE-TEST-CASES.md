### TC-PAGE-001: TabBar 三项路由与图标正确

**优先级**: P1 **类型**: 端到端 **预估时间**: 2 分钟 **执行方式**: LLM

**前置条件**:
- 仓库根 `app.json` 存在且为合法 JSON（`node -e "JSON.parse(require('fs').readFileSync('app.json','utf8'))"` 无报错）
- tabBar.list 含 3 项

**测试步骤**:
1. 读取 `app.json` 的 `tabBar.list`
2. 逐项核对 pagePath 是否为 `pages/index/index`、`pages/records/records`、`pages/mine/mine`
3. 核对每项 iconPath / selectedIconPath 指向的文件存在于 `assets/tabbar/`

**预期结果**:
✅ 3 项 pagePath 与上述完全一致
✅ 6 个图标文件全部存在，无缺失

**通过/失败标准**:
- ✅ 通过：pagePath 与图标全部匹配
- ❌ 失败：任一路径错拼或图标缺失（小程序启动即白屏）

**需关注的潜在缺陷**:
- 分包页面不能进 tabBar（当前无此问题，防回归）
