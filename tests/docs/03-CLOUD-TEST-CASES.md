### TC-CLOUD-001: 家长 push 非法集合全拒

**前置条件**:
- verify_server_guard / verify_pull 套件可用

**测试步骤**:
1. 跑 `node tests/run.js`
2. 核对守卫断言：家长 push students/records/classes 全部 DENY

**预期结果**:
✅ 家长只能 push 允许的集合（如 feedback），其余一律拒绝

- ✅ 通过：白名单拒绝
- ❌ 失败：家长可改评语/学生信息 = P0

**需关注的潜在缺陷**:
- 新增集合忘了进白名单分支（默认放行）
