## 三、⭐TC-REAL-003 新班补齐——分步操作

1. 老师端先正常用一次（进一次记录列表），确认 A 班数据正常
2. 换**负责人账号**：班级管理 → 把老师加进 **B 班**（B 班提前建好且有历史记录；没有就先在 B 班用别的老师账号录几条）
3. 回老师端手机：**彻底杀掉微信**（上滑划掉）→ 重新打开小程序
4. 看结果：
   - ✅ B 班及学生、历史记录自动出现；A 班数据不丢
   - ❌ B 班不出现或历史缺失 → 记 P0
5. 顺手复查：再杀一次进程重开，确认**不会**每次都全量重拉（秒开即正常；每次都转圈 5 秒以上记 P1）

## 四、⭐TC-REAL-004 冲突找回——分步操作

道具：真机 + 开发者工具模拟器，**同一个老师账号**。

1. 两端先各同步一次（确保基线一致），选一条**已有记录**做靶子
2. **模拟器端先改**评语为「版本甲」——改完**不要同步、不要关闭页面**
3. **真机端改**同一条评语为「版本乙」，然后让真机同步（重启小程序或触发同步动作）
4. 回**模拟器端**触发同步（重启小程序最稳）
5. 模拟器端进「存储」页 → 查看新卡片「**被覆盖的改动**」：
   - ✅ 卡片出现，列出「版本甲」内容
   - ❌ 卡片不出现 → 记 P0
6. 点卡片里的**找回**按钮 → 回到那条记录 → 确认评语变回「版本甲」且能再次同步上去
   - ❌ 找回无效 → 记 P0

注意：如果「版本甲」没出现在卡片里，先等 1~2 分钟再进存储页下拉刷新一次。

## 五、TC-REAL-008 断网补传——简版

1. 开飞行模式 → 录 1 条记录（存草稿/直接保存）
2. 关飞行模式，回小程序等 30 秒或重启小程序
3. ✅ 云开发控制台 → 数据库 → 对应集合能看到这条（或另一台设备能看到）
4. ❌ 数据消失 → P0；没自动传、要手动操作才传 → P1 体验问题

